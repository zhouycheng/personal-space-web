# 替换个人资料

这里的资料是虚构示例，不是 JustinWeb 的真实个人内容。将 `resume.json` 和 `projects.json` 复制到 `src/content/site/`，再将 `example-preview.svg` 放到 `src/content/assets/projects/`，即可用匿名内容替换简历与作品记录。项目 ID 保持与文件盒清单一致；如需增减文件，在内容清单中同时调整顺序。

画布卡片、日记 Markdown、头像和 `public/os-desktop/` 文件由各自来源维护；Fork 后应将它们替换为自己的内容。替换前可参照 `LICENSING.md` 核对授权边界。
