# 工作室环境

## 天体与时间

`src/config/studioTime.ts` 使用 SunCalc 2.1 的太阳、月亮位置与月相计算。天空、场景光照、海面反光与加载云雾共享 `EnvironmentSnapshot`。计算使用设备的绝对时间戳和观测经纬度；浏览器时区用于本地日期和时钟显示，不重复叠加时差。

观测点默认使用东部上海，代表经纬度集中在 `src/config/observatories.ts`，另有西部乌鲁木齐、南部广州和北部北京。已有地区偏好从 localStorage 读取；当前标签页已保存且未满 24 小时的定位坐标优先使用。无有效记录时回到代表地区，不自动申请定位。页面不显示天色设置按钮或面板。

配色按太阳高度连续插值，并根据升降趋势区分晨光和金色夕阳。天空顶部、地平线、太阳方向辉光、环境光和云雾分别取色；从深夜、凌晨、黎明、日出、上午、正午、下午、落日过渡到暮光。天体低于地平线时不产生直射光；夜景保留环境光和现有灯具。

日间天空保留适度蓝色，浅海采用青绿色；环境补光在完整日照时为 0.88，直射光保留 2.5，使帆布、木材和沙地通过明暗分出层次。海面保留共享波列的几何起伏，日间细法线随像素覆盖范围减弱，并限制天空反射权重以近似粗糙水面的散射，降低远海碎亮反射；夜间沿用原细法线强度和反射权重。前方沙滩的零散蕨类收拢为两侧植物簇，保留棕榈轮廓、家具与设备位置。

以办公桌所在工作区为基准，北为 -Z、南为 +Z、东为 +X、西为 -X。俯视时上北下南、左西右东；旋转相机不会改变方位。太阳与月亮各自按日期、经纬度计算方位角和高度角，具有季节差异；月亮不固定在太阳对面，可能白天可见，也可能夜间尚未升起。

天空绘制太阳及带明暗面的月亮，视直径约半度。默认镜头俯看海岛，因此天体在高空或镜头背后时可能不在画面内。昼夜亮度依据太阳高度角过渡，方向光在夜间由可见月亮的高度和照明比例控制。天空与海面共享方向参数；海面继续使用原有太阳高光和天空色反射，不单独绘制月亮倒影。

时间通过现有的一秒时钟更新，加载等待期间也更新。隐藏时暂停，恢复时重新读取时间；云雾仅在可见且配色变化时重绘。同步 head 脚本由与运行时相同的计算和存储模块打包，在场景加载之前应用首屏底色。独立加载组件仍可使用自己的默认配色。

## 背景音乐和唱片机

桌面首页顶部采用无底色横排：24px 个人头像、单行窗口监视器状态、短分隔线、曲名与上一首／播放暂停／下一首，右侧为作品、画布、日记、OS 和设置。顶部菜单与底部署名的对齐区域均高 44px，距各自安全区内缘均为 8px，共用垂直间距变量；菜单左右留 24px。头像距安全区顶部 18px，无描边和阴影，13px 暖白文字和细线图标共享中心线，浅色失败背景使用深色文字。头像使用 `src/content/assets/profile-avatar.png`，由 Astro 输出缩小的 WebP，仅展示身份。曲名最长 180px，超长省略；641–900px 隐藏曲名，状态限宽 88px，完整保留导航与播放控制。顶部空白区域不截获场景操作，底部签名保持水平居中；手机签名仍距底部安全区 24px。

活动状态复用画布的 `activityCopy` 和活动订阅，优先展示描述，无描述时使用原状态标题，只在桌面首页可见时连接。状态默认隐藏，仅在收到未过期的有效活动数据后显示；加载、连接失败、无活动和状态过期时隐藏且不占空位，重新收到有效数据后恢复。状态无气泡背景，不显示个人名字。

桌面点击底部签名可隐藏或显示整条顶部菜单，使用 160ms 渐入渐出；签名保持原位置和可见性，支持键盘 Enter／Space。隐藏后菜单立即退出交互，活动订阅暂停。显隐偏好仅保留在当前 shell 内，进入内页再返回时保留，刷新重置。≤640px 的签名为普通文字，手机探索入口不受桌面隐藏状态影响；减少动态效果时立即切换。

手机（≤640px）左上角不显示头像或音乐控件。完整设置放入现有探索面板的“音乐”页：手机通过底部“探索”进入，桌面通过右上角设置图标进入。面板内提供小唱片、曲名、上一首、播放/暂停、下一首和音量，不新增独立弹窗。顶部控件与面板同步播放状态；仅一首时顶部隐藏切歌按钮。跨入手机断点时，顶部音乐按钮的焦点交给“探索”。应用 shell 持有一个原生 audio，站内进入作品、画布、日记和 OS 不重建音频；离开首页时顶部 160ms 淡出并退出交互，探索面板关闭，音乐继续播放，减少动态效果时立即切换。首次打开及刷新后等待用户主动播放，localStorage 只保存曲目 ID 和音量。加载失败停止唱片并提供重试；无有效曲目时顶部音乐区连同分隔线隐藏，设置页显示“暂无音乐”并禁用播放。场景加载失败时音乐页仍可访问。

将音频放入 `public/music/`，在 `src/content/site/music.json` 添加 `{ "id": "稳定标识", "name": "曲名", "artist": "可选作者", "src": "/music/文件名.mp3" }`。列表默认空；音频地址必须是站内绝对路径，多首按顺序循环。只添加拥有网站使用授权的音频。

播放器 UI 和浏览器音频状态由 `src/presentation/ui/music/` 管理，偏好存储由 infrastructure/client 管理。应用层将真实 playing、pause、waiting、error 状态映射到 `ScenePort.setMusicPlaying`，场景模块不读取 DOM 音频控件。重新创建场景时重放当前播放状态。

床头柜位于桌子右侧后方，朝内斜放；位置和朝向由 `workspaceAppearance.recordPlayer` 管理。唱片机包含木质底座、金属转盘、唱片沟槽、纸标、轴孔、唱臂配重与唱针。转盘和唱臂通过现有场景帧循环更新，暂停保留唱片角度，唱臂回到抬起停靠状态。后台和全屏暂停场景帧时不新增计时器；减少动态效果和轻量模式使用静态唱片，保留播放状态对应的唱臂位置。资源沿用场景集合统一释放。

## 篝火和地毯

篝火参考 [Muddy Faces 的实景火塘](https://muddyfaces.co.uk/activities/bushcraft-survival/fires-fire-pit-designs)：不规则石圈、错落木柴、炭床以及沿木柴间隙上升的火焰。石头使用平滑几何和颜色变化，木柴使用独立长度、落点、树皮凹凸与局部炭裂纹。`campfireFlame.ts` 在 WebGL 中对局部火体进行有界光线步进，使用上升湍流生成火舌和内部明暗；火体随已有风场摆动，保留 reduced-motion 和后台暂停控制。

三把营地椅保留现有位置和朝向，`campChair.ts` 构造圆角木条、交叉转轴、扶手、布套和缝线。薄帆布沿同一参数曲面生成下垂和卷边，避免厚方块式坐垫。外形参考木架帆布折叠椅，不加载外部模型。

桌下及懒人沙发下的地毯保留原位置和覆盖范围，使用 `woolRug.ts` 的哑光羊毛材质、细密织纹和短绒纤维。织纹随像素覆盖范围衰减，纤维在初始化时生成并合批，不在每帧生成。所有几何、材质和纹理由现有场景资源集合释放。

## 浅海生态带

岛的西侧、西北侧和东北侧分散分布五块近中景礁体，外海两处岩群增加五块远景礁体。卷叶状、脑状与分枝珊瑚错开礁体布置。三群近岸鱼每群十二条，其中三条使用橙白条纹的小丑鱼配色，其余为银灰色小鱼；一只带盾片纹理与宽前鳍的海龟在西侧独立游动。鱼体长为 0.54，三群各沿不同离岸距离游动。鲨鱼在约 6.6 倍岸线半径的远侧外海巡游，沿海浪高度调整吃水，主要露出背鳍、脊背和尾尖。正前方沙滩与东侧码头保留开阔水面。

远海分散布置七座独立岩岛，离岛中心 145–365 个世界单位，各自使用不同的岸线比例与山脊峰形，形成长礁、孤立尖礁、双峰岩岛和低平浅礁。方向与距离错开，岛间保留开阔海面。远岛仅在主通道合并绘制一次，共 3360 个三角形；距离雾随天空地平线颜色和昼夜光照变化，不参与水下通道。

`src/config/marineLife.ts` 管理布局、数量、尺度和周期，`src/animation/studio/marineMotion.ts` 按共享海洋时间计算位置与朝向。模型使用连续曲面，鱼群采用实例化绘制与顶点摆尾。海洋物体属于环境布景，排除在交互拾取和缩放锚点候选之外。

`marineEnvironment.ts` 使用主相机的独立渲染层，将海洋物体与海床遮挡深度写入离屏颜色和深度纹理；水面根据前后深度、距离吸收与反光合成立体水下内容。边缘扭曲在深度连续时生效。露出水面的礁体与鲨鱼由主通道绘制；两个通道共享原有场景光照，新增物体不投射动态阴影。颜色在线性空间合成，最终由水面完成色调映射。

离屏纹理按绘图缓冲区计算：桌面宽高使用 65%，长边上限 1280；画布 CSS 宽度不超过 600 时使用 50%，长边上限 1024。几何与材质进入场景资源集合，离屏目标在销毁时独立释放。减少动态效果、轻量模式、后台隐藏和内容全屏沿用海洋暂停机制，恢复时从已保存的海洋时间继续。性能面板的调用与三角形统计涵盖离屏和主场景两个通道。

## 渲染预算与细节

工作室场景创建时附带全局调试面板，默认隐藏。macOS 按住 `⌘+Shift` 并将指针移入左下角 56 像素热角触发；其他平台使用 `Ctrl+Shift`。临时面板在指针移出时自动收起，也可按 `Escape` 或点击右上角 `×` 手动关闭。开发时可在 `.env.development.local` 设置 `PUBLIC_SCENE_DEBUG_PANEL=true`，面板会常驻；此设置只在 Astro 开发服务器中生效。生产构建中的常驻开关必须为 `false`，但快捷键和热角仍可临时打开面板。

`.github/workflows/scene-debug-panel-policy.yml` 是可复用的生产开关检查工作流，并由 `deploy.yml` 在发布前调用。它读取 GitHub Actions 仓库变量 `PUBLIC_SCENE_DEBUG_PANEL`：缺省按 `false` 处理；若配置为 `true` 或其他非布尔值，主工作流会在发布镜像前失败。Dockerfile 的生产构建参数默认也是 `false`。

面板保留深色背景和浅绿色文字，采用等宽文本与横线分隔，不使用指标卡片或装饰性品牌标题。可拖动右下角或使用“面板尺寸”滑块调整宽高，尺寸保存在当前浏览器；文本区独立滚动。信息包含场景 FPS、活动帧间隔 P50/P95/最大值、超过 50/100 毫秒的慢帧、场景更新和 WebGL 提交 CPU 耗时、输入到绘制的延迟、长任务、绘制调用、三角形、着色器程序、阴影刷新、植被 LOD、几何与纹理计数及错误记录。页面显示区域和绘图缓冲区以像素分别列出，同时显示设备 DPR、当前渲染 DPR 和横纵向实际比例，避免把 CSS 尺寸与物理像素混为一谈。

面板可以单独显隐工作区设备、遮阳棚、岛屿装饰、休闲设施和海岛环境；也可切换全局线框、坐标轴与阴影，调节镜头方位、俯仰、缩放、测试时刻和渲染 DPR。快捷按钮可直接切换白天、黄昏、夜景、线框、坐标轴、阴影和海岛环境，并提供恢复默认场景。测试时刻通过宿主的同一环境计算入口更新天空、光照与尚可见的加载云雾，保留当前观测位置，不持久化；选择“真实时间”后回到设备时钟。渲染比例可恢复页面默认值。静止时场景按需绘制，场景提交频率会降为 0；它不代表屏幕呈现 FPS。WebGL 未提供 GPU 执行耗时，面板会把 renderer 的 CPU 提交时间与 GPU 实际执行明确区分。

设备进入和返回过场从屏幕几何包围盒读取实际宽高，同时支持圆角电脑屏幕和矩形 iPad 屏幕。过场不依赖 `PlaneGeometry.parameters`，避免更换屏幕几何后产生无效相机坐标。

植被叶片按植物分组，共享三档几何的顶点属性，只在初始化时建立不同内部索引。各档保留全部叶片及其外沿顶点，完整档保留原有三角形；法线、颜色与风锚点在切换时不重建。细节误差按原始网格与简化三角形的偏差估算，并为风形变保留余量。进入较粗档要求误差不超过 0.4 个物理像素，超过 0.5 像素返回精细档，同时限制太阳阴影的误差；扩大包围球覆盖最大风位移。颜色和阴影通道使用同一细节档，切换时使阴影失效。所有档位归场景资源集合释放，停止渲染时不独立运行更新循环。

海面岩石距离场先排除完整影响范围之外的像素，再计算局部距离；泡沫和海底岩影在贡献归零后截断。船舱排水先检查包围范围，再进行原有船体坐标变换和截面判断。浅水底色与焦散在贡献小于阈值时渐退；波列、海面网格、法线贴图、反光与岸线保持共用模型。沙地接触暗部复用同一噪声采样，并跳过权重严格为零的范围。

使用已经启动的生产构建运行 `PERF_URL=http://127.0.0.1:4327 PERF_LABEL=current rtk node scripts/island-performance-measure.mjs`。脚本固定 1440×900、DPR 1.5、昼间光照和正常动态效果，在有界面的硬件 Chromium 上重复三次静置、旋转反向和缩放反向，保存原始记录到 `.workspace/performance-upgrade/`。渲染提交间隔、CPU 提交时间和输入到提交延迟分别记录，不把它们当作 GPU 执行时间或屏幕呈现时间。降低动态效果仅用于计时之后的截图，不用于性能样本。
