# 工作室环境

## 天体与时间

`src/config/studioTime.ts` 使用 SunCalc 2.1 的太阳、月亮位置与月相计算。默认观测点为上海（31.2304°N、121.4737°E），由 `studioObservatory` 集中配置；不申请访客定位。计算依据真实时间戳，浏览器时区仅影响桌面时钟的显示，不改变同一时刻的天体位置。

以办公桌所在工作区为基准，北为 -Z、南为 +Z、东为 +X、西为 -X。俯视时上北下南、左西右东；旋转相机不会改变方位。太阳与月亮各自按日期、经纬度计算方位角和高度角，具有季节差异；月亮不固定在太阳对面，可能白天可见，也可能夜间尚未升起。

天空绘制太阳及带明暗面的月亮，视直径约半度。默认镜头俯看海岛，因此天体在高空或镜头背后时可能不在画面内。昼夜亮度依据太阳高度角过渡，方向光在夜间由可见月亮的高度和照明比例控制。天空与海面共享方向参数；海面继续使用原有太阳高光和天空色反射，不单独绘制月亮倒影。

时间通过现有的一秒时钟更新；隐藏和全屏页面的渲染暂停规则保持不变。

## 篝火和地毯

篝火参考 [Muddy Faces 的实景火塘](https://muddyfaces.co.uk/activities/bushcraft-survival/fires-fire-pit-designs)：不规则石圈、错落木柴、炭床以及沿木柴间隙上升的火焰。石头使用平滑几何和颜色变化，木柴使用独立长度、落点、树皮凹凸与局部炭裂纹。`campfireFlame.ts` 在 WebGL 中对局部火体进行有界光线步进，使用上升湍流生成火舌和内部明暗；火体随已有风场摆动，保留 reduced-motion 和后台暂停控制。

三把营地椅保留现有位置和朝向，`campChair.ts` 构造圆角木条、交叉转轴、扶手、布套和缝线。薄帆布沿同一参数曲面生成下垂和卷边，避免厚方块式坐垫。外形参考木架帆布折叠椅，不加载外部模型。

桌下及懒人沙发下的地毯保留原位置和覆盖范围，使用 `woolRug.ts` 的哑光羊毛材质、细密织纹和短绒纤维。织纹随像素覆盖范围衰减，纤维在初始化时生成并合批，不在每帧生成。所有几何、材质和纹理由现有场景资源集合释放。

## 渲染预算与细节

工作室场景创建时附带性能调试面板，开发和生产构建均默认隐藏。macOS 按住 `⌘+Shift` 并将指针移入左下角 56 px 触发，再重复组合键切换显示；其他平台使用 `Ctrl+Shift`。面板在场景释放时一并清理。

面板显示场景绘制提交频率、活动绘制间隔分位数与长间隔数、每帧场景更新及 Three.js `renderer.render` 的 CPU 时间、相机请求到下一次绘制的时间、浏览器 Long Task、绘制次数、三角形数、着色器程序数、阴影刷新帧数、视口与绘图缓冲尺寸、DPR、WebGL 上下文和 GPU renderer、相机参数、动画开关、阴影灯、植被 LOD、几何与纹理计数及运行时异常。静止时场景采用按需绘制，场景 FPS 会降为 0；它统计的是场景提交，不代表屏幕呈现 FPS。WebGL 没有提供有效计时扩展时，GPU 执行时间不可读，面板会明确显示这一点。

设备进入和返回过场从屏幕几何包围盒读取实际宽高，同时支持圆角电脑屏幕和矩形 iPad 屏幕。过场不依赖 `PlaneGeometry.parameters`，避免更换屏幕几何后产生无效相机坐标。

植被叶片按植物分组，共享三档几何的顶点属性，只在初始化时建立不同内部索引。各档保留全部叶片及其外沿顶点，完整档保留原有三角形；法线、颜色与风锚点在切换时不重建。细节误差按原始网格与简化三角形的偏差估算，并为风形变保留余量。进入较粗档要求误差不超过 0.4 个物理像素，超过 0.5 像素返回精细档，同时限制太阳阴影的误差；扩大包围球覆盖最大风位移。颜色和阴影通道使用同一细节档，切换时使阴影失效。所有档位归场景资源集合释放，停止渲染时不独立运行更新循环。

海面岩石距离场先排除完整影响范围之外的像素，再计算局部距离；泡沫和海底岩影在贡献归零后截断。船舱排水先检查包围范围，再进行原有船体坐标变换和截面判断。浅水底色与焦散在贡献小于阈值时渐退；波列、海面网格、法线贴图、反光与岸线保持共用模型。沙地接触暗部复用同一噪声采样，并跳过权重严格为零的范围。

使用已经启动的生产构建运行 `PERF_URL=http://127.0.0.1:4327 PERF_LABEL=current rtk node scripts/island-performance-measure.mjs`。脚本固定 1440×900、DPR 1.5、昼间光照和正常动态效果，在有界面的硬件 Chromium 上重复三次静置、旋转反向和缩放反向，保存原始记录到 `.workspace/performance-upgrade/`。渲染提交间隔、CPU 提交时间和输入到提交延迟分别记录，不把它们当作 GPU 执行时间或屏幕呈现时间。降低动态效果仅用于计时之后的截图，不用于性能样本。
