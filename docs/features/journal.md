# 3D 日记

日记只在工作室中的实体书阅读。Markdown 是正文的唯一维护来源；客户端使用固定页图和点击区域，不包含全文 HTML。WebGL 或资源错误显示独立提示、重试与返回入口。

## 写作和生成

源文在 `src/content/journal/`，保留已有 slug。元信息包括标题、日期、描述；段落生成稳定锚点。日记插图按原路径维护，现有个人图片不做转换或替换。

```bash
npm run journal:setup       # 首次安装锁定版本的分页 Chromium
npm run journal:build       # 编译、分页、完整校验并激活
npm run journal:verify      # 不启动浏览器，核对源和当前包
npm run build               # 验证已有包、构建并验证 dist
npm run build:release       # 显式生成后完成上述构建
```

普通 `dev` 不需要 Chromium。有有效包即可阅读；内容更新后显示 `outdated`，缺包显示 `missing`。普通生产构建严格拒绝缺失、过期或损坏包。合法空内容生成空包，源目录读取失败则报错。

生成使用 `.node-version` 和锁文件中的 Playwright、Paged.js、字体及图像工具。分页为 420×594 CSS px，正文 16px、1.75 行高，页图为 3× 分辨率；优化不降低正文分辨率、阴影或采样质量。字体 `public/journal/fonts/NotoSerifSC.woff2` 附 OFL 文本。

## 不可变包

```text
public/journal/generated/
  current.json                  唯一激活点
  manifest.json                 当前激活包的运行时索引
  <renderHash>/
    manifest.json
    pages/<index>.webp
    thumbnails/<index>.webp
```

`contentHash` 覆盖正文、元信息、slug、清洗和锚点代码及相关依赖版本；`renderHash` 再覆盖插图、字体、布局、生成代码和环境描述。使用稳定相对路径。同一套计算用于生成、开发校验和生产构建。验证读取生成环境记录，不为查询浏览器版本启动 Chromium，也不因验证平台不同拒绝有效包。

生成器获取输出目录锁，在独立临时目录冻结并处理输入，验证后再次检查源指纹。完整版本目录就位后原子替换 `current.json`，随后派生运行时索引。活进程锁不可夺取；中断或源变化不激活半成品。`--force` 对同一个版本生成不同字节会失败，不覆盖已有 URL。

校验覆盖 manifest 结构、连续页码、文章范围、slug、锚点、点击区域、目录边界、每个图片的完整解码、尺寸、长度与 SHA256。服务端健康检查使用生产文件和 Node 内置能力复核校验值，不依赖生成工具或源码。

当前有效包及 `current.json`、运行时索引纳入 Git；未激活的本地包和临时目录忽略。生成后同步 `.gitignore` 中的版本 allowlist，将新包作为一组可审阅变更。不要手改生成图片和清单。一次阅读会话固定使用进入时的版本，资源过期会要求重新加载。

## 阅读控制与交互

应用控制器的阶段为：

```text
stowed → preparing → extracting → observing → opening
       → reading ↔ turning → closing → observing → returning → stowed
```

可用性独立表示 `loading / ready / empty / missing / outdated / error / recovering / unsupported`。有效页、必需纹理绑定及正确姿态的一次绘制完成后，才提交阅读位置。失败或取消不更新稳定书签。

日记固定在桌面左上角。进入时镜头靠近书本上方并自动翻开，书本保持位置与大小，抽屉状态保持独立。夜间且台灯关闭时自动打开台灯，退出后保持开启。阅读时底部显示“合拢”和页码；合拢后可点击封面或按 Enter 重新打开。滚轮、双指或键盘加减调整镜头距离，Home 或 0 重置阅读视角。文章 URL、显式锚点和书签定位文章及页码，跨文章阅读替换当前 URL。

书本复用唯一的工作室 renderer，始终摊开为双页。宽屏同时看两页；窄屏镜头聚焦一页，点左右边缘先移到同一组的另一页，越过双页边界才翻纸。反向阅读按相反顺序执行，末页不越界。调整屏幕尺寸保留页码。拖动只微调镜头：水平偏角限制为 ±10°，俯视偏角限制为 4°–16°，相机上方向对齐纸页，不能把文字转倒；书本位置、朝向和大小不随拖动改变。链接和插图优先命中；有效 pointerdown/up 必须属于同一手势。

页角翻动会保留抓取角、二维拖动方向和松手速度，用细分纸页网格表现扭转与弯曲，并限制局部扭转角。翻动页与底页共用纸叠曲面，书脊边保持固定，抬升从书脊向外增加；翻动网格横向细分与底页对齐，避免接近落平时相交。拖动距离按画布宽度估算单页宽度的 82%，松手后使用阻尼回弹。点击和键盘翻页使用随翻页次序轻微变化的起始姿态。

手机左右切页只改变阅读镜头，跨越双页边界时使用纸页弯曲、绕脊和阻尼落页算法；桌面支持页角拖动。当前及翻动所需的正反面纹理提前准备，避免切换阅读侧时临时请求。

Escape 依次关闭插图、合上日记、返回工作室；加载、错误、恢复或过场时可取消并退出。返回时书本留在桌上，镜头恢复进入前视角，抽屉不受影响。新导航使旧操作失效；取消结果与完成结果分开。

后台暂停活动时间。BFCache 挂起保留实例，页面恢复时检查路由与可见性；最终销毁释放资源。减少动态效果仍执行资源准备、目标姿态和有效绘制。

## 资源预算

| 项目 | 限制 |
| --- | --- |
| 请求并发 | 3 |
| 解码并发 | 2 |
| 常驻页纹理 | 最多 4，正文以 3× 分辨率生成 |
| CPU 解码及预留 | 48 MiB |
| GPU 纹理估算及预留 | 64 MiB，包含 mipmap 估算 |
| 排队翻页 | 最多一个最新有效意图 |

当前可见页和翻页正反面固定，预取优先让位。页数上限并不代表总能放满四页，字节预算可能先达到。材质解绑后分别 dispose Texture、关闭 ImageBitmap；退出开始取消预取，归位后释放全部页工作集。再次进入利用 HTTP 缓存重新准备。

翻动纸张使用绕脊、弯曲与单页折叠算法。一次形变计算供正反面共用位置和法线，反面 UV、内容纹理与材质独立；替换同通道页纹理不重复失效材质程序，首次绑定或移除纹理时正常更新。

进入阅读时按过场进度渐入与纸页纹理相乘的局部补光，保证夜间文字可读，保留法线明暗；返回时同步减弱。桌面与场景保持可见，棚布沿用镜头遮挡淡出机制。

文章清单、顺序和总页数以当前激活包的 manifest 为准。

纹理计数及估算字节不是显存实测。性能比较必须记录浏览器渲染后端、视口、DPR、光照、缓存和至少三次重复。

## 测试与运行

`test:unit` 检查纯规则、取消语义、生成包与适配器，不启动 Chromium。`test:journal:render` 执行真实分页和完整性测试。`test:startup:no-browser` 在隔离项目验证开发和普通构建。`test:e2e` 复用统一 Playwright 服务、日志与上下文；测试目标是构建站点，不隐式生成书页。`test:e2e:release` 先完整生成构建。

Docker builder 安装分页浏览器，runner 只复制 dist 与生产依赖。`start` 从 `dist/server/entry.mjs` 启动；生产服务不读日记源码。`/api/health` 保留桌面与画布字段并包含日记可用性和版本，生产坏包返回 503，开发缺包可报告日记降级。

自动化移动触摸不等于普通手机性能实测，Playwright WebKit 不等于真实 Safari。
