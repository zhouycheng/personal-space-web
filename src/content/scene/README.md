# Ocean surface asset

`waternormals.jpg` is the unmodified water normal texture from the Three.js r186 examples:
https://github.com/mrdoob/three.js/blob/r186/examples/textures/waternormals.jpg

Copyright © 2010–2026 three.js authors. Distributed under the MIT license; see `three-LICENSE.txt`.
The asset is bundled locally. It stores normal directions, not display colors, and must stay in linear/no-color-space mode.
